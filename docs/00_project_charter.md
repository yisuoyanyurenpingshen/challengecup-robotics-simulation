# SmartClean-Sim 项目章程

## 赛题与定位

- 榜题编号：DG-202604
- 题目名称：面向智慧环卫场景的国产系统无人清扫车关键技术攻关
- 发榜单位：北京地平线信息科技有限公司

项目正式定位：

> SmartClean-Sim：面向 RDK 国产机器人平台的智慧环卫无人清扫车仿真与边缘部署验证系统。

## 当前最小闭环

第一阶段先建立可重复、可测试的 PC 仿真闭环：

1. 接收自然语言或结构化清扫任务。
2. 将任务转换为受约束的数据对象。
3. 加载垃圾点、静态障碍、积水区和动态行人场景。
4. 使用 A* 规划清扫路径，并在动态障碍出现时安全重规划。
5. 执行清扫与返航，输出完成率、覆盖率、路径长度、碰撞和重规划次数。

二维核心只依赖 Python 标准库，目的是让算法、接口和指标在 ROS2、Gazebo、GPU 或开发板尚未就绪时仍可验证。

## 范围

当前范围：

- 确定性二维栅格仿真
- 规则式中文任务解析和结构化任务接口
- 垃圾、障碍、危险区、动态障碍的数据模型
- A* 路径规划、任务执行和基础指标
- ROS2、感知模型、LLM、RDK 的适配边界设计

后续范围：

- Gazebo 场景和机器人模型
- ROS2 节点、Topic、Action 与 Nav2 集成
- YOLO 垃圾识别与像素坐标到地图坐标转换
- 受 JSON Schema 约束的 LLM 任务分解
- Web 控制面板
- ONNX 导出、量化、BPU 编译和 RDK 板端实测

当前不宣称：

- 已完成实车或 RDK 板端部署
- 已验证工业级定位、识别、避障或清扫效率指标
- 二维真值仿真结果等同于真实道路性能

## 工程原则

- LLM 只生成结构化任务，不能直接控制底盘。
- 所有实验结果必须关联代码版本、配置和场景。
- “目标值”“仿真结果”“板端结果”“实车结果”必须明确区分。
- 公共目录每次变更都要更新 `logs/`；接口或技术决策变化还要更新 `docs/`。
